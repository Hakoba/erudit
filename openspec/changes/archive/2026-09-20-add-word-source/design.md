# Design: источник слова

## Context

Запись — `DictionaryEntry` в `storage.local`, доступ только через `useDictionary`;
`addEntry` при повторном добавлении мержит поля (`??` для необязательных).
Слова со страницы добавляют три места: оверлей (`ChapterOverlay.vue`: закладка,
«добавить все», выделение) и боковая панель Chrome (`side-panel/pages/index.vue`),
у которой свой `location` — адрес вкладки она знает только из `usePanelChannel`
(`currentUrl`), заголовка не знает. Фильтры экрана словаря — `DictionaryFilters`
и `queryEntries` в `utils/dictionary.ts` (чистый модуль с тестами), список уровней
собирает `levelFilterOptions`.

## Goals / Non-Goals

**Goals:**
- Источник пишется бесплатно там, где он есть, и не ломает записи без него.
- Фильтр по хосту устроен так же, как фильтр по уровню.

**Non-Goals:**
- Отдельная таблица страниц: денормализованный URL на запись стоит ~200 байт,
  при лимите `storage.local` в 10 МБ это сдвигает потолок с ~20 до ~14 тысяч слов.
- Поле `Source` в Anki: `MODEL_ID` фиксирован, и смена набора полей у типа заметки
  ломает обновление уже импортированных колод. Отдельным решением, если попросят.
- Группировка списка по источнику — фильтра хватает.

## Decisions

**1. Два строковых поля, хост считается на лету.** `sourceUrl`, `sourceTitle`
в `DictionaryEntry`; `sourceHost(entry)` в `utils/dictionary.ts` через `new URL`
с откатом в пустую строку. Хранить хост отдельно — третье поле ради экономии
одного `new URL` на рендер.

**2. Нормализация в одном месте.** `pageSource(url, title)` в `utils/dictionary.ts`:
`origin + pathname`, заголовок `trim` и срез до 120. Оверлей зовёт её
с `location.href`/`document.title`, панель — с данными из снимка. Тест рядом.

**3. Панель получает источник в снимке.** В `PanelState` поле
`page: { url: string; title: string }`; оверлей кладёт его в `publishPanelState`.
`currentUrl` из `usePanelChannel` не подходит: заголовка там нет, а адрес вкладки
может уже уйти вперёд от снимка, по которому пользователь жмёт «добавить».

**4. Источник не перезаписывается.** `addEntry` мержит `sourceUrl ?? existing.sourceUrl`,
как остальные необязательные поля: первое место встречи важнее последнего,
и повторное «добавить все» не переписывает половину словаря.

**5. Фильтр по хосту — копия фильтра по уровню.** `host: string` в `DictionaryFilters`,
`hostFilterOptions(entries)` собирает уникальные хосты с числом записей, `Select`
рядом с уровнем, показывается только при непустом списке. Ссылка в строке —
`<a target="_blank" rel="noreferrer noopener">` с текстом «хост · заголовок»,
заголовок обрезается CSS.

## Risks / Trade-offs

- [Читалки с SPA: адрес меняется без перезагрузки] → оверлей пересоздаётся
  по смене `origin+pathname`, `location.href` в момент добавления актуален.
- [Заголовок сайта — мусор («(12) Reddit»)] → показываем как есть, это
  ссылка, а не поле для чтения.
- [Записи из выделения на странице без оверлея] → выделение живёт в оверлее,
  без него добавления нет.
