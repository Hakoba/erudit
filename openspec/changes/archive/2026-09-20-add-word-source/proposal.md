# Источник слова: откуда оно пришло

## Why

Запись словаря не помнит, где слово встретилось: только предложение-контекст.
С демо-набором и «Добавить все» словарь быстро переваливает за сотню слов,
и становится непонятно, откуда что. Вернуться к странице по слову нельзя,
отфильтровать «слова с reddit» нельзя. Триггер из `deferred.md` («Источник слова»)
сработал.

## What Changes

- У записи словаря появляются необязательные поля `sourceUrl` (адрес страницы
  без query и хэша) и `sourceTitle` (заголовок, до 120 символов). Старые записи
  остаются без источника, миграция не нужна.
- Источник заполняют все точки добавления со страницы: закладка в строке слова,
  «Добавить все», выделение текста — из оверлея и из боковой панели Chrome
  (панель получает адрес и заголовок вкладки в снимке состояния).
- Ручная форма, импорт из Anki и демо-набор источник не пишут.
- На экране словаря у записи ссылка «откуда» (хост и заголовок, ведёт на страницу)
  и фильтр по хосту рядом с фильтром уровня; список хостов собирается из записей.

## Capabilities

### New Capabilities

- `word-source`: хранение адреса и заголовка страницы у записи словаря, показ
  ссылки на источник и фильтр по хосту.

### Modified Capabilities

_нет: `demo-dictionary` и `immersion-mode` не меняются — демо-набор источника
не имеет, подмена слов на источник не смотрит._

## Impact

- `src/types/words.ts` — два поля в `DictionaryEntry`.
- `src/utils/dictionary.ts` — `sourceHost(entry)`, фильтр по хосту в `DictionaryFilters`,
  `hostFilterOptions`; тесты рядом.
- `src/utils/panelBus.ts`, `content-script/overlay/ChapterOverlay.vue`,
  `ui/side-panel/pages/index.vue` — источник в снимке панели и в `addEntry`.
- `ui/options-page/pages/dictionary.vue` — ссылка и фильтр.
- `src/locales/*` — строки во всех шести локалях.
- Экспорт в Anki, резервная копия, тренировка не меняются: копия снимает хранилище
  целиком, новые поля попадают в неё сами.
